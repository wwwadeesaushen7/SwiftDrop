# Windows download — SwiftDrop 0.3.0

The new **version-checked Windows build is pending**. A verified 0.3.0 installer has not yet been published by this workflow.

**[Open the Windows installer build](https://github.com/wwwadeesaushen7/SwiftDrop/actions/workflows/windows-download.yml)**. Its installer artifact will be named **SwiftDrop-0.3.0-Windows-installer-COMMIT**. Open that artifact, extract it, and check for **SwiftDrop-0.3.0-windows-x64-setup.exe**.

After a successful build and publication, this page will automatically show the direct EXE download, size, SHA-256 and source commit. A build failure will be reported here rather than substituting a 0.2.0 installer.

The older generic **SwiftDrop-Windows** artifact name does not identify a version. Confirm the setup filename before installing. Close the older app before updating. Version 0.3.0 has **GitHub files → Push files / Pull files**.
